# Status meanings and support

Customer/affiliate workflow status tags are not yet released. A request being received must not be interpreted as a confirmed booking, completed vehicle return, issued document or settled payment. Published steps and screenshots will follow verified releases.

For operational questions contact your rental business. For developer integrations use the versioned public API reference. Customer account, payment, referral, document and notification FAQs will be added when those workflows exist; no sign-in or configuration procedure is currently available for those portals.
